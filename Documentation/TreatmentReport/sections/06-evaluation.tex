\section*{Evaluation protocol}
\textbf{Formative inspection.} Seek 3--5 evaluators with HCI/VR knowledge where available. Inspect the environment against the course's Nielsen adaptations and VR-specific heuristics \cite{gain}. Report issue, task, heuristic, severity and proposed correction. Do this before a larger user study.

\textbf{Novice pilot.} Target five introductory learners for a small formative pilot, subject to course recruitment and consent requirements. This sample is for finding problems, not proving learning effectiveness. Record prior VR and chemistry experience; allow seated or standing use. Explain how to pause or stop and stop on discomfort.

Record timestamps and observations on a worksheet or screen recording with participant agreement. The current software does not automatically collect research telemetry. Ask short post-task questions about clarity, control, perceived challenge, room credibility and comfort; label these as custom formative questions, not a validated flow scale.

\textbf{Comparison.} If the pilot reveals unclear bonding cues, compare two threshold/effect settings using the same tasks and counterbalanced order. Change one factor at a time. Keep results descriptive and report previous-task learning effects.

\textbf{Device acceptance.} Run the full lesson repeatedly and a 20-minute Quest 3 session. Record headset software, APK hash, CPU/GPU frame times, dropped frames, memory and thermal behaviour. Target sustained 72 FPS; include both hands and controllers, sleep/resume, reset during reaction and tracking interruptions.
