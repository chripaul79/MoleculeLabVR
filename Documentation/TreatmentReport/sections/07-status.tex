\section*{Architecture and editable content}
The academic environment is an editable prefab in the MoleculeLab Environment folder. Runtime initialization uses its bench, tray, panel and socket references. Chemistry definition generation preserves the existing scene. Decorators should edit the prefab or scene, not regenerate the environment to make small changes.

AtomInventory owns the finite token ledger. Loose atoms and molecule views reference identities; reactions and fragment operations transfer ownership. BondPlacement is the common pure placement evaluator; BondPreview presents its outcome. This separation supports testing rules independently of headset input.

The catalogue now includes H2O, CH4, C2H6, H2, O2, C2H4, C2H2, CH3OH, C2H5OH, CO2 and C6H6. A new molecule requires authored geometry and bonds, an inventory feasibility check and interaction testing. Arbitrary structure generation remains outside this treatment.

\end{itemize}
